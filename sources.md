## Update process
1. A monthly check produces a change report (flag-only: the deck is never edited automatically).
2. For each confirmed change, edit the value in this file **and** in the data in `build_deck.py`.
3. Rebuild the deck with `python build_deck.py`.
4. Update the **Baseline as-of** date above and add a change-log entry.
